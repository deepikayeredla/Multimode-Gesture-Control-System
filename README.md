Overview:

This project implements a real-time multi-mode gesture control system that enables users to control system functions using hand gestures captured through a webcam. Built using MediaPipe and OpenCV, the system provides seamless, touch-free control of screen brightness, volume, and media playback, offering an intuitive human–computer interaction experience.

The project also integrates gesture usage analytics to analyze interaction patterns and improve usability and personalization.

Features:

>> Real-time hand landmark detection using MediaPipe

>> Multi-mode gesture control system

>> Brightness control

>> Volume control

>> Media playback control

>> Smooth mode switching based on finger count

>> Gesture usage analytics

>> Low-latency and responsive performance

>> Modular and extensible architecture

Technologies Used:

>> Python

>> MediaPipe

>> OpenCV

>> NumPy

System-level APIs for device control

Working Principle

>> The webcam captures live video frames.

>> MediaPipe detects hand landmarks in real time.

>> The number of fingers detected determines the control mode:

i) One finger: Brightness control

ii) Two fingers: Volume control

iii) Three fingers: Media playback control

>> Hand movements are mapped to corresponding system actions.

>> Gesture usage data is logged for analytics and personalization.
